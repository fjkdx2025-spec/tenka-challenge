# どうぶつ添加物チャレンジ

食品添加物の摂取をゲーム感覚で記録できる Web アプリです。

- 毎日 100pt の「げんきポイント」が、添加物をとるたびに減っていき、アバターの体調が変わります
- 平たいおもち形のてがき風どうぶつアバター（うさぎ・ねこ・ねずみ ほか）と、たくさんの着せ替えアイテム
- デイリーミッション・連続記録・バッジ・レベル
- ミニゲーム（ベジキャッチ／てんかぶつクイズ／ペアさがし）でごほうびアイテムをゲット
- 食品表示の文字を貼り付けて添加物を読みこみ

## 動かし方
`index.html` 1ファイルだけで動きます（ビルド不要）。GitHub Pages で公開しています。

## 注意
ポイントは表示されている添加物の種類をもとにしたゲーム用の目安です。健康への影響を示すものではありません。
